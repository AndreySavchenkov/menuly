# Menuly — SaaS landing page (demo)

A responsive marketing landing page for a fictional QR digital-menu SaaS.
Built as a portfolio project by **Andrei Sauchankau**.

**Live demo:** https://menuly-murex.vercel.app

## Features

- Live phone mockup with **3 switchable menu themes** and category tabs
- Light / dark mode (respects system setting, remembered in localStorage)
- Monthly / yearly pricing toggle
- Accessible FAQ accordion, mobile navigation, skip link
- Email form with client-side validation and loading / success states
- Mobile-first, no horizontal scroll down to 320px, `prefers-reduced-motion` support

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · lucide-react

## Run locally

```bash
npm install
npm run dev
```
